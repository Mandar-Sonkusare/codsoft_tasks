# CODSOFT Web Development Internship

This repository contains three web development projects completed as part of the CodSoft Level 1 internship tasks. Each project demonstrates proficiency in HTML, CSS, and JavaScript with a focus on responsive design and clean code.

## Tasks

### Task 1 - Personal Portfolio
A professional personal portfolio website showcasing education, skills, and projects at the intersection of Technology, Finance, and AI.

**Technology:** HTML, CSS, JavaScript

**Features:**
- Responsive navigation with mobile hamburger menu
- Hero section with call-to-action buttons
- About section with profile information
- Skills showcase organized by category
- Project gallery with detailed descriptions
- Resume download section
- Contact information with social links
- Smooth scrolling and scroll animations
- Fully responsive design for all devices

### Task 2 - Landing Page
A modern landing page for "FINTECH AI" - a fictional AI-powered financial insights platform.

**Technology:** HTML, CSS, JavaScript

**Features:**
- Fixed navigation with smooth scrolling
- Engaging hero section with animated floating cards
- Solutions section with feature cards
- How It Works section with step-by-step process
- Why section with benefits and statistics
- Call-to-action section
- Comprehensive footer with multiple sections
- Premium fintech aesthetic design
- Fully responsive layout

### Task 3 - Calculator
A fully functional calculator with a clean, modern interface.

**Technology:** HTML, CSS, JavaScript

**Features:**
- Basic arithmetic operations (+, −, ×, ÷)
- Decimal number support
- Percentage calculation
- Clear (AC) and backspace functions
- Division by zero error handling
- Keyboard support for all operations
- Visual feedback with operator highlighting
- Chained calculations
- Professional UI with CSS Grid layout
- Responsive design for mobile and desktop

## How to Run

Each project is self-contained and can be run independently:

1. **Clone or download this repository**
2. **Navigate to any task folder:**
   - `Task-1-Portfolio/`
   - `Task-2-Landing-Page/`
   - `Task-3-Calculator/`
3. **Open the `index.html` file in your web browser**

No build process, dependencies, or server setup required. Simply open the HTML files directly in any modern web browser.
